Pill CTA button — one per ad, copy from the CTA list («Sacar turno», «Consultar por WhatsApp», «Ver tratamientos»).

```jsx
<Button variant="primary">Sacar turno</Button>
<Button variant="dark">Consultar por WhatsApp</Button>
<Button variant="secondary" size="web">Ver tratamientos</Button>
```

- On an #8cc3c8 block use `dark` (primary would disappear). On #22343a use `primary` or `onDark`.
- Never white text on #8cc3c8.
