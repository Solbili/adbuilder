Jost Light headline with the brand's single italic-teal word — the signature of every Smile Lab piece.

```jsx
<Headline text="Limpieza dental con turno por *WhatsApp*." />
<Headline text="Odontología para *chicos*." tone="dark" />
```

- Never bold. To gain legibility raise the size (H1 ≥ 72px on 1080).
- Only the first *word* becomes italic; extra asterisks are rendered plain.
- Italic color per tone: light #4d9199 (headline sizes only, 3.4:1), dark #8cc3c8, accent #1b2c31, photo #bfdfe0.
